        About FileSync

        FileSync sends files from one device to many in real time. Open a room, share the link or QR code, and anyone who joins can send and receive files. No accounts, no installs, and no size limit.

        How it works

        Files travel directly between browsers over WebRTC, encrypted in transit. The server only helps devices find each other. When a direct path isn’t possible, an encrypted relay passes the data along without being able to read it.

        Links shared from the room include a security key after the #. Browsers never send that part to any server. When you join with it, FileSync confirms that nobody, not even the server, is sitting between you and the host, and shows Verified. A room code typed by hand still works, without that check.

        Every file is checked with SHA-256 when it arrives, and interrupted transfers continue from where they stopped.
